# 2.3.9 и 2.3.9д: две кнопки и долгое нажатие

Проект для обычной Raspberry Pi Pico / RP2040. Первая кнопка подключается между
**GP15 (ножка 20)** и GND, вторая — между **GP14 (ножка 19)** и GND.
Можно использовать соседнюю землю на ножке 18. Подтяжки включены в прошивке.
Используется встроенный светодиод Pico на GP25.

## Поведение

- **Первая кнопка, короткое нажатие:** после отпускания светодиод переходит
  по кругу «выключен → включён → мигает → выключен».
- **Первая кнопка, удержание:** через 1 с после подтверждения нажатия светодиод
  однократно переходит в мигание. Короткое действие не выполняется ни при нажатии,
  ни при отпускании. Продолжение удержания и дребезг при отпускании не повторяют действие.
- **Вторая кнопка:** сразу после подтверждения нажатия меняет период
  250 → 500 → 1000 → 250 мс. Её удержание не повторяет переключение.
- Обе кнопки работают независимо; для нажатия и отпускания используется фильтр 20 мс.
  При запуске светодиод мигает с периодом 1000 мс.

Счётчики команды `button` увеличиваются при подтверждении физического нажатия,
один раз на жест независимо от его длительности.

## Загрузить прошивку

Из корня репозитория соберите проект, как предыдущие задания:

```powershell
cmake -S 239-two-buttons -B 239-two-buttons/build -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build 239-two-buttons/build --parallel
```

Требуются Pico SDK, Arm GNU Toolchain, CMake, Make и picotool.
В Windows при необходимости задайте путь к Make через `-DCMAKE_MAKE_PROGRAM`.
Готовый файл — `239-two-buttons/build/239_two_buttons.uf2`.
При подготовке задания он уже собран локально. В Git готовые файлы не добавляются
по правилу задания 1.1.4.

Удерживая BOOTSEL, подключите Pico по USB, отпустите кнопку и скопируйте UF2 на
диск RPI-RP2. Плата перезапустится. Кнопки подключайте при отключённом USB.
У 2.3 и 3.1 разные прошивки: для проверки этого задания загрузите именно
`239_two_buttons.uf2`.

## Проверить в вузе

1. Нажмите и отпустите первую кнопку три раза. Каждый раз состояние LED должно
   меняться только после отпускания.
2. Отключите LED командой `led_disable` в USB-терминале (115200, CR или LF).
   Удерживайте первую кнопку 3–4 секунды: примерно через секунду LED начинает
   мигать и продолжает после отпускания.
3. Во время удержания первой кнопки нажимайте вторую. Период мигания меняется;
   его значение можно прочитать командой `led_blink`.
4. Удерживайте вторую кнопку и нажимайте первую. Первая продолжает различать жесты,
   а период меняется только один раз за нажатие второй.
5. Команда `button` показывает состояния и счётчики обеих кнопок, `info` —
   `project: 239-two-buttons`.

## Автоматические проверки

Проверки курса `check-2-3-9.yml` и `check-2-3-9d.yml` запускаются в GitHub Actions.
Проверка 2.3.9д статическая, отдельный лог с платы для неё не нужен.

Исполняемые тесты на компьютере проверяют C-код задачи: короткое нажатие,
порог 1 с, отсутствие повторов при удержании и дребезге, отпускание до порога,
независимость кнопок, необязательные обратные вызовы и 64-разрядные часы.

```powershell
cmake --build tests/host/build --config Debug
ctest --test-dir tests/host/build -C Debug --output-on-failure
```

Физическая проверка на плате выполняется в вузе; программные тесты её не заменяют.
