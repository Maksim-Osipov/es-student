# Готовая прошивка

Файл `311_adc.uf2` и его SHA-256 входят в скачиваемый комплект; в Git хранятся исходники,
как требует проверка 1.1.4 курса.

На GitHub откройте [сборку комплекта](https://github.com/Maksim-Osipov/es-student/actions/workflows/adc-firmware.yml),
выберите последний успешный запуск и скачайте **Artifacts → es-student-3.1-ready**.
Там находятся UF2 и архив проекта с инструкцией.

Локально готовый UF2 также лежит в этой папке после подготовки комплекта.
Чтобы собрать заново, используйте команды из `311-adc/README.md`.
